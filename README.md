# Emroschool — Honar Media Platform

Web platform for a school and creative institute — courses, media, admissions and
content management. Built with Next.js (App Router), TypeScript, Tailwind CSS,
Drizzle ORM and PostgreSQL.

## Quick start

```bash
npm install
cp .env.example .env
npx prisma db push
npm run dev
```

## Scripts

- `npm run dev` — development server
- `npm run build` / `npm start` — production build and start
- `npm test` — test suite (`tests/`)

See `docs/` for setup guides (Firebase push, vendor notes).
